# FizzBuzz

Scrivi `fizzBuzz(n)` che restituisce un array di `n` stringhe, per i numeri da 1 a `n`:

- `"FizzBuzz"` se il numero è divisibile per 3 e per 5;
- `"Fizz"` se è divisibile solo per 3;
- `"Buzz"` se è divisibile solo per 5;
- altrimenti il numero scritto in cifre (per esempio `"7"`).

Se `n` è 0 restituisce un array vuoto. Se `n` è negativo o non è intero lancia un `RangeError`.
