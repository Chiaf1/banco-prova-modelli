Regex for standard form: ^M{0,3}(CM|CD|D?C{0,3})(XL|XC|L?X{0,3})(IX|IV|V?I{0,3})$ — careful order: hundreds: (CM|CD|D?C{0,3}), tens: (XC|XL|L?X{0,3}), units: (IX|IV|V?I{0,3}). Also must not match empty string — but M{0,3} etc all optional, so "" matches. Need to exclude empty. Check s.length > 0 or use a lookahead. Actually "" should throw. Add check.

Also note: regex like (CM|CD|D?C{0,3}) — "D?C{0,3}" allows "DCC" etc. Fine.

Parse: map values, subtractive handled naturally by summing with rule: if value < next value, subtract. Since only standard forms accepted, simple sum works too because standard form values are non-increasing except subtractive pairs...
